# 🍔 Swiggy Data Analysis Dashboard (Power BI)

## 📌 Project Overview

This project focuses on analyzing **Swiggy food delivery data** using **Power BI** to uncover actionable business insights related to revenue, customer behavior, restaurant performance, and food category trends.

The dashboard is designed to help stakeholders quickly understand **key performance indicators (KPIs)** and make data-driven decisions through interactive visualizations.

---

## 🎯 Objectives

* Analyze overall **revenue and order performance**
* Understand **customer spending behavior** using AOV
* Identify **top-performing cities, restaurants, and dishes**
* Evaluate **category-wise revenue contribution**
* Measure **customer satisfaction** through ratings

---

## 📊 Key KPIs

* **Total Revenue:** ₹53.01M
* **Total Orders:** 197K
* **Average Order Value (AOV):** ₹268.51
* **Revenue Growth:** 14.69%
* **Total Restaurants:** 984
* **Total Cities:** 28
* **Total Dishes:** 54K
* **Average Rating:** 4.34

---

## 📈 Dashboard Features

* Interactive slicers for:

  * State
  * City
  * Category
  * Restaurant Name
  * Order Date
* Revenue analysis by:

  * State & City (Map + Bar Chart)
  * Restaurant Name
  * Dish Name
  * Food Category
* Top restaurants comparison with:

  * Total Orders
  * Total Revenue
  * Average Rating

---

## 🔍 Key Insights

* Metro cities like **Bangalore, Hyderabad, and Mumbai** contribute the highest revenue
* Popular QSR brands (KFC, McDonald's, Pizza Hut) dominate total orders and revenue
* **Main Course and Combo categories** generate maximum revenue
* Strong **average rating (4.34)** indicates high customer satisfaction
* AOV of ₹268 reflects a **mid-range spending pattern** among users
